**Works with Admiral, the one tray app for the Air 99.**

## What's new

- **Hands the keys to Admiral.** [Admiral](https://github.com/yourgirljolyne/Admiral) runs the now-playing card, your custom keys in software mode and FN + arrow screen switching from one tray icon. While Admiral is running, DeckMapper's background key service steps back and Admiral plays your keys, so nothing is ever typed twice. Close Admiral and the service picks them up again.
- **Changes reach Admiral straight away.** After every **Apply to keyboard** (or restoring a backup), DeckMapper tells Admiral to read your keys again.
- **Closing the window exits** while Admiral runs, since there's nothing left for DeckMapper to do in the background.

Without Admiral, everything works exactly as in 1.1.0.

## Get it running

1. Download **DeckMapper.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable**.
4. Run it. If you use Admiral, update DeckMapper to this version: 1.1.0 doesn't know about Admiral and keeps playing the keys itself (Admiral then steps back).
