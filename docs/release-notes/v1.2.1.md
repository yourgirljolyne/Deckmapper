**Safer writes, and a way back when a profile gets replaced.**

## What's new

- **Import a backup into a new profile.** If the keyboard's profile is replaced (for example iCUE creates a new one), DeckMapper's backups no longer fit: the new profile reuses the old file numbers for other things, so Restore refuses. `DeckMapper import <backup folder>` shows how the backup's keys would go into the profile the keyboard has now, and `--apply` does it: assignments, key mappings and dial modes are copied as they were, after checking that every action and macro file they use is still on the keyboard. Nothing is deleted.
- **Every write is read back.** Apply, Restore and Import now read each file back after writing it and stop at the first one that doesn't match, before anything points at it.

## Please update

If you run SignalRGB, don't use DeckMapper 1.0: it can mistake SignalRGB's replies for its own and write into the wrong file. 1.1 and later skip replies meant for other programs.

## Get it running

1. Download **DeckMapper.exe** below.
2. Install the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) if you don't have it.
3. Plug the keyboard in with the **USB cable**.
